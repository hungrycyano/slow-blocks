# ゆっくりテトリス(slow-tetris)

初心者でも、あせらずに遊べるテトリスです。
勝ち負けや点数はありません。ブロックを積んで、**模様を作って楽しむ**ゲームです。

## はじめかた

- `index.html` をダブルクリックして、ブラウザで開くだけで遊べます(サーバーやインストールは不要です)。
- GitHub Pages に、このフォルダをそのまま置けば公開できます。

ファイルは次の3つです。

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の部品(盤面、ボタンなど) |
| `style.css` | 見た目(色、並べ方) |
| `game.js` | ゲームの動き(設定値は先頭にまとめてあります) |

## 遊び方

- ブロックは **2秒に1段** だけ、ゆっくり落ちてきます。何個積んでも、レベルが上がっても、**速くなりません**。
- 左右に動かしたり回転させたりして、好きな場所に置きましょう。
- **模様モード**(はじめはオン)では、横一列がそろっても消えません。積んだブロックがそのまま模様になります。
  オフにすると、ふつうのテトリスのように、そろった列が消えます。
- 盤面がいっぱいになると「いっぱいになりました」と出ます。「もう一度」か「盤面を全部消す」を選んでください。
- できた模様は「画像で保存」で、PNG画像として保存できます。

### 操作方法

| 操作 | キーボード | 画面のボタン |
|---|---|---|
| 左へ動かす | ← | ◀ |
| 右へ動かす | → | ▶ |
| 回転 | ↑ または Z | 回転 |
| 下へ速く落とす | ↓(押している間だけ) | ▼(押している間だけ) |
| ゆっくり | S | ゆっくり |
| やり直し | U | やり直し |
| 一時停止 | P | 一時停止 |

- ←→ を押しっぱなしにすると、一定の間隔でくり返し動きます。
- ↓ や ▼ で速く落としたブロックが置かれると、次のブロックはふつうの速さに戻ります(もう一度押すと、また速く落ちます)。

### べんりな機能

- **ゆっくり**:押すと、落ちる速さが一時的に、さらに5倍遅く(10秒に1段)なります。約15秒で元に戻ります。もう一度押すと、すぐ戻ります。
- **やり直し**:直前に置いたブロックを取り除き、同じ形のブロックを上に戻します。20手前まで戻れます。
- **レベル**:置いたブロックの数でレベルが上がり、ブロックの形が複雑になります(速さは変わりません)。
  - レベル1:1マス、2マス、3マスの、かんたんな形
  - レベル2:レベル1の形 + 4マスの形(I・O・T・S・Z・J・L)
  - レベル3:レベル2の形 + 5マスの形(F・I・L・N・P・T・U・V・W・X・Y・Z)
  - 「はじめのレベル」で、最初からレベル2や3を選ぶこともできます。
- **色の設定**:形ごとに好きな色を選べます。選んだ色はブラウザに保存されます。「色をもとに戻す」で最初の色に戻せます。

## 設定値の変え方

`game.js` をテキストエディタ(メモ帳など)で開くと、いちばん上に「設定」がまとめてあります。
数字を書きかえて保存し、ブラウザを再読み込みすると反映されます。

| 設定値 | はじめの値 | 意味 |
|---|---|---|
| `FALL_INTERVAL_MS` | `2000` | ブロックが1段落ちる間隔(ミリ秒。1000 = 1秒) |
| `SOFT_DROP_INTERVAL_MS` | `60` | ↓ や ▼ を押している間に1段落ちる間隔(ミリ秒) |
| `SLOW_MULTIPLIER` | `5` | 「ゆっくり」のとき、落ちる間隔を何倍にするか |
| `SLOW_DURATION_MS` | `15000` | 「ゆっくり」が続く長さ(ミリ秒。15000 = 15秒) |
| `UNDO_LIMIT` | `20` | 「やり直し」で何手前まで戻れるか |
| `LEVEL2_COUNT` | `20` | 何個置いたらレベル2になるか |
| `LEVEL3_COUNT` | `40` | 何個置いたらレベル3になるか |
| `BOARD_COLS` | `10` | 盤面の横のマス数 |
| `BOARD_ROWS` | `20` | 盤面の縦のマス数 |
| `KEY_REPEAT_DELAY_MS` | `200` | ←→ を押しっぱなしにしたとき、くり返しが始まるまでの時間(ミリ秒) |
| `KEY_REPEAT_INTERVAL_MS` | `100` | ←→ のくり返しの間隔(ミリ秒) |

例:もっとゆっくりにしたいときは、`FALL_INTERVAL_MS` を `3000`(3秒)にします。

ブロックの形は、`game.js` の `SHAPES`(形のリスト)に、マスの座標で書いてあります。
`[x, y]` の組を足したり消したりすると、形を変えたり、新しい形を足したりできます。

## 作らないもの

- 落ちる速さが上がるしくみ(どこにも入れていません)
- 音
- 点数やランキング
